MovieApp

A simple mobile application built using React Native and Expo that allows users to browse and explore movies.

 Features
- View movie list
- Search movies
- View movie details
- Simple and responsive UI

Technologies
- React Native
- Expo
- TypeScript

 Installation

```bash
npm install
npx expo start
```
